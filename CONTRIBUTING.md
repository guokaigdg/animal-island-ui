# Contributing to animal-island-ui

Thanks for your interest! Issues and pull requests are welcome.

The full contributor guide lives in
[`docs/development/contributing.md`](docs/development/contributing.md) — issue/PR flow,
Conventional Commits, and the pre-commit hook that runs `npm run ci`.

Start there, then read the rest of [`docs/development/`](docs/development/README.md) for
repository structure, component development, coding standards, testing, and the build
contract. Coding agents should start from [`AGENTS.md`](AGENTS.md).

Quick essentials:

```bash
npm install        # also installs the pre-commit hook
npm run dev        # demo dev server
npm run ci         # must pass before any PR
```
